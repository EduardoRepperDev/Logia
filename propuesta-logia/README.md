# Propuesta visual Logia — Carpeta de assets

Esta carpeta NO forma parte del scaffold de Laravel. Contiene los assets, referencias y briefs para generar la propuesta visual del rediseño en Framer / v0 / Lovable.

## Plazo: 24 horas

## Estructura

```
01-marcas/          → logos, iconos y screenshots de las 4 marcas que vende Logia
02-empresa/         → fotos reales del equipo, oficinas, certificaciones DC-3
03-clientes/        → logos top 10 (cinta) + fotos de los 6 testimoniales
04-referencias/     → screenshots de Linear, Stripe, Vercel, Arc, Notion, moodboard
05-contenido-real/  → textos, precios, stats, planes de membresía
06-brief/           → brief para pegarle a la IA + feedback del cliente
07-videos-hero/     → 3-5 videos cinematográficos en loop para el hero
08-personas/        → banco de fotos humanas (ejecutivos, trabajo, reuniones, capacitaciones)
```

## Orden de trabajo (24h)

1. **Hora 0-3**: llenar todas las carpetas con los assets que ya tienes
2. **Hora 3-4**: terminar `06-brief/brief-final.md` y `06-brief/feedback-cliente.md`
3. **Hora 4-6**: subir todo a Framer + generar 3 variantes de hero
4. **Hora 6-12**: iterar sección por sección (hero → stats → productos → testimoniales → banner → membresías → marcas → cinta → academia → footer)
5. **Hora 12-18**: pulido, animaciones, responsive
6. **Hora 18-22**: publicar URL temporal + capturas
7. **Hora 22-24**: revisión propia + ajustes finales antes de mandar al cliente

## Reglas anti-look-IA (no negociables)

- NO gradientes morado-rosa-azul
- NO iconos 3D flotantes
- NO stock photos genéricas
- NO fondo blanco puro
- NO todo centrado
- NO headlines de más de 10 palabras
- NO cards todas del mismo tamaño
- NO avatares con iniciales
